# GDGOC Kickoff Event Website

An informative, semantic HTML5 webpage built for the **Google Developer Groups on Campus (GDGOC) Kickoff Event at COMSATS University Islamabad, Attock Campus**.

## Features
- **Semantic HTML5 Structure:** Uses `<header>`, `<nav>`, `<main>`, `<section>`, `<form>`, and `<footer>`.
- **Custom Theme:** Dark Navy Blue & Black theme with Glassmorphism section cards and background image.
- **Community Teams Showcase:** Highlights all 7 core teams with special centered layout for Women in Tech.
- **Registration Form:** Fully structured community sign-up form with input validation.
